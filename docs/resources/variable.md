# adaptive_variable (Resource)

Variables keep shared or secret values out of resource configuration. Reference
the variable by name with Mustache syntax such as `{{database_host}}`.

## Example Usage

```terraform
resource "adaptive_variable" "database_host" {
  name   = "database_host"
  value  = "postgres.internal.example"
  labels = ["production", "database"]
}

resource "adaptive_resource" "postgres" {
  name = "production-postgres"
  type = "postgres"
  host = "{{database_host}}"

  depends_on = [adaptive_variable.database_host]
}
```

## Schema

### Required

- `name` (String) Workspace-unique variable name. Use it in resource configuration as {{name}}. Changing it replaces the variable.
- `value` (String, Sensitive) Secret or configuration value substituted into resource configurations at runtime.

### Optional

- `labels` (Set of String) Permission labels attached to the variable.

## Import

Import a variable with its Adaptive ID:

```shell
terraform import adaptive_variable.database_host <variable-id>
```
