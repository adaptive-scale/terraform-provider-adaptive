# adaptive_dlp_policy (Resource)

The `adaptive_dlp_policy` resource defines a Data Loss Prevention policy that restricts how data can leave sessions on protected endpoints. Policies can:

- **Block screenshots** of protected sessions
- **Block clipboard copy/paste** in and out of sessions
- **Block file transfer** (upload/download)
- **Block or cap bulk exports** with a maximum row count
- **Block session log export**
- **Block entire access surfaces** (e.g. `webshell`)
- **Carve out exceptions** with expr-lang expressions (e.g. `"sre" in teams && deviceTrusted`)

Attach a policy to an endpoint via the `dlp_policy` attribute of `adaptive_endpoint`, target labeled data with `applies_to_labels`, or make it the workspace default with `workspace_default`.

~> The Adaptive server upserts DLP policies **by name**, and the policy name is the Terraform resource ID. Renaming a policy therefore creates a new policy on the server; the previously named policy is deleted, which also clears any endpoint/workspace references to it. Treat `name` as a stable identifier.

## Example Usage

### Strict PII Policy

```terraform
resource "adaptive_dlp_policy" "pii_strict" {
  name        = "pii-strict"
  description = "Strict controls for endpoints handling PII"
  enabled     = true

  block_screenshot         = true
  block_clipboard_copy     = true
  block_clipboard_paste    = false
  block_file_transfer      = true
  block_bulk_export        = true
  max_export_rows          = 500
  block_session_log_export = true

  blocked_surfaces  = ["webshell"]
  exceptions        = ["\"sre\" in teams && deviceTrusted"]
  applies_to_labels = ["pii"]
  workspace_default = false
}
```

### Workspace Default Policy

```terraform
resource "adaptive_dlp_policy" "baseline" {
  name              = "workspace-baseline"
  description       = "Baseline DLP controls for every endpoint"
  block_screenshot  = true
  block_bulk_export = true
  max_export_rows   = 10000
  workspace_default = true
}
```

### Policy Attached to an Endpoint

```terraform
resource "adaptive_dlp_policy" "pii_strict" {
  name                 = "pii-strict"
  block_screenshot     = true
  block_clipboard_copy = true
  block_bulk_export    = true
  max_export_rows      = 500
  applies_to_labels    = ["pii"]
}

resource "adaptive_endpoint" "protected" {
  name       = "postgres-pii-access"
  resource   = adaptive_resource.postgres.name
  users      = ["analyst@example.com"]
  dlp_policy = adaptive_dlp_policy.pii_strict.name
}
```

## Exception Expressions

The `exceptions` list holds [expr-lang](https://expr-lang.org/) expressions. A session matching any expression is exempt from the policy. Expressions are validated by the Adaptive server during `terraform apply`; an invalid expression fails the apply with the server's validation message.

```terraform
resource "adaptive_dlp_policy" "with_exceptions" {
  name             = "prod-dlp"
  block_screenshot = true
  exceptions = [
    "\"sre\" in teams && deviceTrusted",
    "user.email endsWith \"@example.com\" && requestApproved",
  ]
}
```

## Schema

### Required

- `name` (String) Name of the DLP policy. Must be unique within the workspace. Renaming creates a new policy on the server (the old one is removed along with its endpoint/workspace references).

### Optional

- `applies_to_labels` (List of String) Data labels the policy applies to (e.g. pii).
- `block_bulk_export` (Boolean) Block bulk data exports from protected sessions.
- `block_clipboard_copy` (Boolean) Block copying data out of protected sessions via the clipboard.
- `block_clipboard_paste` (Boolean) Block pasting data into protected sessions via the clipboard.
- `block_file_transfer` (Boolean) Block file upload/download in protected sessions.
- `block_screenshot` (Boolean) Block screenshots of protected sessions.
- `block_session_log_export` (Boolean) Block exporting session logs/recordings.
- `blocked_surfaces` (List of String) Access surfaces the policy blocks entirely (e.g. webshell).
- `description` (String) Human-readable description of the policy.
- `enabled` (Boolean) Whether the policy is enforced. Defaults to true.
- `exceptions` (List of String) expr-lang expressions describing sessions exempt from the policy (e.g. `"sre" in teams && deviceTrusted`). Expressions are validated by the Adaptive server; invalid expressions fail the apply with the server's message.
- `max_export_rows` (Number) Maximum number of rows a single export may return when bulk export blocking is enabled. 0 means no row limit.
- `workspace_default` (Boolean) Whether this policy is the workspace-wide default. Defaults to false.

### Read-Only

- `id` (String) The ID of this resource.
- `policy_id` (String) Server-side identifier of the policy.

## Import

DLP policies can be imported using the policy name:

```shell
terraform import adaptive_dlp_policy.example pii-strict
```
